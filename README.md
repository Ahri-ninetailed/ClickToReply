# ClickToReply

**English** · [Русский](#русский)

A tiny World of Warcraft addon: **left-click on the text of a player's chat message** and the chat edit box opens in the same channel with `Name, ` already typed. Just write your answer and press Enter.

- Works for Say, Yell, numbered channels (`/1`, `/2`, ...), Guild, Officer, Party, Raid and Instance chat.
- Clicks on the timestamp, channel name, player name, links (items, quests, players) or empty space are ignored, so the usual chat behaviour stays the same.
- If you have already started typing something, the addon does not touch your text.
- Shift/Ctrl/Alt + click and dragging the chat window are ignored.
- Your own messages, whispers and system messages are ignored.
- The addon does not replace or filter chat messages and does not override any Blizzard functions.

Game version: **WoW Forever** (Interface 16001).

## Installation

Install via the CurseForge app, or download the archive from [Releases](../../releases) and unpack the `ClickToReply` folder into `World of Warcraft\_forever_\Interface\AddOns`.

## Русский

Небольшой аддон для World of Warcraft: **ЛКМ по тексту сообщения игрока в чате** открывает поле ввода в том же канале с уже набранным `Имя, `. Осталось написать ответ и нажать Enter.

- Работает в каналах «Сказать», «Крик», номерных каналах (`/1`, `/2`, ...), гильдии, офицерском, группе, рейде и подземелье.
- Клики по времени, названию канала, нику, ссылкам (предметы, задания, игроки) и пустому месту игнорируются, поэтому обычное поведение чата не меняется.
- Если вы уже начали что-то писать, аддон ваш текст не трогает.
- Клики с Shift/Ctrl/Alt и перетаскивание окна чата игнорируются.
- Свои сообщения, шёпот и системные сообщения игнорируются.
- Аддон не подменяет и не фильтрует сообщения чата и не переопределяет функции Blizzard.

Версия игры: **WoW Forever** (Interface 16001).

## Установка

Через приложение CurseForge или скачайте архив из [Releases](../../releases) и распакуйте папку `ClickToReply` в `World of Warcraft\_forever_\Interface\AddOns`.
